# HOME

This file is configuration, not a page. The leading underscore keeps the build
from turning it into one.

Everything above the `---` line is what appears on the landing page: the name,
the role, the one-line tagline, the About paragraph and the contact block.

To change any of it, edit the value and run `python3 build/build.py`.

**Contact fields are optional.** A field left blank simply does not appear on
the page — no empty row, no placeholder. `linkedin` and `phone` are blank
because they were never supplied. Fill them in like this and they show up:

    linkedin: https://www.linkedin.com/in/your-profile
    phone: +966 5X XXX XXXX

Remember the site is public: anything written here is readable by anyone with
the link.
