# MY COURSEWORK

## CCTV · Fundamentals | Corvit Systems | classes 01–03
summary: What CCTV is, where it came from, and the shopping list for a working network.

### What CCTV means | class 01 · 17 Oct 2023
- CCTV stands for closed circuit television
- Television is a Greek word — *tele* means far, *vision* means view
- Two types of television: OCTV and CCTV
- OCTV — open circuit television: television set, wires and antenna, watched over a free or paid video network, used for entertainment
- CCTV — closed circuit television: DVR/NVR, wires and connectors, watching is limited and restricted, used for security
- master: 90

### History of CCTV | class 01 · 17 Oct 2023
- Introduced by German scientist Walter Bruch in 1942
- First use was to capture the scene of a rocket launch
- First commercial use was traffic monitoring
- Now used in homes, shops, offices, restaurants, schools
- master: 90

### Surveillance systems | class 01 · 17 Oct 2023
- Surveillance is a French word meaning monitoring
- Observing or monitoring an area or object is called a surveillance system
- Other types of surveillance: computer, mobile, telephone, surveillance cameras, biometric, social network
- master: 90

### Requirements for creating a CCTV network | class 01 · 17 Oct 2023
- DVR or NVR
- Cameras
- Cables — coaxial, coaxial + power, CCTV cable, ethernet
- Connectors — BNC connectors and BNC leads
- RCA cable
- LCD screen
- Hard disk
- DC 12 volt adapter
- Access point and internet
- CCTV tester
- master: 90, 94

### Network and CCTV tester | class 03 · 19 Oct 2023
- Network — connectivity of two or more devices so they communicate with each other
- CCTV tester — a device used to adjust the covering area of analog cameras
- Internet — connect DVR/NVR to the internet to reach it from anywhere in the world
- master: 92

## CCTV · Recorders, cameras & cabling | Corvit Systems | classes 02–03
summary: The hardware layer — what each box does, what plugs into it, and which cable goes where.

### What is a DVR | class 02 · 18 Oct 2023
- DVR stands for digital video recorder
- The central or main device in a CCTV network — all cameras connect to it
- A channel is a port used for camera connectivity on the DVR
- Available in 4, 8, 16, 32 and 64 channel models
- By default a DVR has no storage — a hard disk must be installed
- Without a hard disk you can only view cameras on screen, not record
- With a DVR you can view footage, store video, search video, do event-based recording and scheduled recording
- Only analog cameras can connect to a DVR
- master: 91

### What is an NVR | class 02 · 18 Oct 2023
- NVR stands for network video recorder
- The central or main device for IP cameras
- Connect the NVR to a switch, and connect all cameras to that switch
- All DVR features are available in an NVR
- master: 91

### Cameras | class 02 · 18 Oct 2023
- CCTV cameras are also known as surveillance cameras
- They capture image and video and forward it to the DVR or NVR
- Two types — analog cameras, and digital or IP cameras
- master: 90

### Wires and cables | class 02 · 18 Oct 2023
- Wire is the heart of a CCTV network
- Coaxial cable, coaxial + power cable and CCTV cable run between DVR and analog cameras
- Ethernet cable runs between NVR and IP cameras
- master: 94

### Connectors | class 02 · 18 Oct 2023
- BNC connectors — used at the start and end of coaxial, coaxial + power and CCTV cable
- RJ-45 connectors — used at the start and end of ethernet cable
- BNC leads — can be used instead of BNC connectors at either end
- Hard disk — by default there is none in the DVR, it must be installed
- master: 94

### RCA cable and display | class 03 · 19 Oct 2023
- RCA stands for Radio Corporation of America
- RCA cable connects DVR to a television screen to view the CCTV setup
- Also used for older-version voice cameras
- LCD screen connects to DVR/NVR through VGA or HDMI cable
- VGA stands for Video Graphics Array
- HDMI stands for High Definition Multimedia Interface
- VGA carries video only; HDMI carries both video and audio
- master: 94

### Power and access | class 03 · 19 Oct 2023
- DC 12 volt adapter powers the DVR, NVR and cameras
- Access point — connect it to the DVR/NVR to reach the setup from mobile or laptop over signal without internet
- master: 94

### DVR rear panel layout | class 03 · 19 Oct 2023

- master: 91

### What each port does | class 03 · 19 Oct 2023
- Channel — a port used for camera connectivity in the DVR
- V-out — video out, used to view cameras on a television screen
- A-out — audio out, used to connect a speaker to the DVR for listening
- VGA and HDMI — used to view the CCTV setup on an LCD screen
- Audio-in — connects audio devices or audio cameras to the DVR
- RJ-45 — connects the DVR to an access point or the internet
- USB — universal serial bus, connects mouse and keyboard, and takes video off the DVR
- Power button — on/off button of the DVR
- DC-12 volt — powers the DVR
- RS-485 — connects sensors and alarms to the DVR
- master: 91

## CCTV · Cable termination | Corvit Systems | classes 04–05
summary: Making up coaxial and coaxial + power cable by hand, step by step.

### Configuring coaxial cable and connectors | class 04 · 20 Oct 2023
- Requirements — coaxial cable (RG-6 or RG-7), BNC connector, screwdriver, cutter
- Step 1 — remove the coat or cover from the coaxial cable; underneath are two conductors, the copper wire and the mesh
- Step 2 — attach the main copper wire (the video wire) under the screw of the BNC connector, then tighten the screw onto it
- Step 3 — attach the mesh to the external side of the BNC connector
- Step 4 — attach one side of the cable to the DVR and the other side to the camera
- master: 94

### Configuring coaxial + power cable, RG-59 | class 05 · 23 Oct 2023
- Requirements — RG-59 cable, BNC connector or BNC lead, DC 12 volt adaptor, cutter
- Step 1 — remove the coat and cover from the coaxial wire
- Step 2 — attach the BNC connector or lead to the coaxial wire
- Step 3 — cut the DC 12 volt adapter wire at the centre; it contains two wires
- Step 4 — attach the DC 12 volt wire to the red wire of the RG-59 cable, and attach the second wire to the black wire, at both ends
- master: 94

## CCTV · NVR and IP cameras | Corvit Systems | classes 15–19
summary: The IP side of the course — NVR hardware, first setup, and managing added cameras.

### What is an NVR | class 15 · 07 Nov 2023
- NVR stands for network video recorder
- It is the central device in an IP camera network
- Connect all IP cameras to a simple switch or a PoE switch
- Connect the NVR and the switch to each other
- A unique IP address must be assigned to each IP camera and also to the NVR
- Every camera must be added manually in the NVR
- By default an NVR has no storage — a SATA hard disk must be installed
- Like DVR and XVR, all features are available in an NVR
- master: 91

### Physical structure of an NVR | class 15 · 07 Nov 2023
- RJ-45, also called the LAN port — connects the NVR and switch to each other
- Audio-in — connects an audio device
- Audio-out — connects external speakers
- HDMI and VGA — video display and output ports
- VGA carries video only, HDMI carries both audio and video
- USB port — used for NVR configuration with mouse and keyboard, and to take video recordings onto USB from the NVR
- DC-12 volt — gives power to the NVR
- On/off button
- master: 91

### Installing a hard disk in an NVR | class 16 · 08 Nov 2023
- Remove the external screws of the NVR, then remove the cover
- Connect the SATA wire (the video wire) and the power wire between the hard disk and the NVR motherboard
- Fix the cover back on the NVR and tighten the screws
- master: 91

### Configure a fresh NVR | class 16 · 08 Nov 2023
- Power on the NVR → select language, English → Apply → click Yes on the resolution notification
- Set the admin password → Activate → set a valid email → Apply
- Click Security question → provide answers → Apply
- Manual configure → draw the admin pattern
- Set date and time → Next → give the IP address, static or DHCP → Next
- Check the installed hard disk → click Init (initialize) → OK — the hard disk is formatted and status changes from abnormal to R/W
- Check the cameras and select all → Add all
- Click Edit on those cameras which are in disable state → provide the password, because the camera is another vendor → OK → status goes green → Next → Finish
- master: 91

### NVR resolution, default and password prompt | class 16 · 08 Nov 2023
- Restore to vendor default — right-click → Menu → Maintenance icon → Factory default → OK → the NVR reboots and is restored
- Set resolution — right-click → Menu → Setting → System → General sub tab → set resolution → Apply
- Enable or disable password asking — right-click → Menu → Setting → tab → General sub tab → enable or disable lock screen password on Basic setting → Apply
- master: 91

### Add, delete and activate cameras in an NVR | class 17 · 09 Nov 2023
- Delete a camera — right-click → Menu → Setting → Camera → Camera sub tab → click on the camera → click the delete icon
- Add an IP camera — Setting → Camera → Camera sub tab → click Edit in front of IP/operation → provide the camera password → OK
- Camera activation password, when an added camera is not showing on screen — Setting → Camera → on that camera click Edit under operation → check Use camera activation at the bottom → OK
- Format the hard disk — Setting → Record → Storage → select HDD → click Init (initialize) → OK — status changes from abnormal to RW (read and write)

### Manage added cameras | class 18 · 10 Nov 2023

- Change IP address and password of an added camera — Setting → Camera → Camera sub tab → click the IP address of the added camera → click the setting icon → change IP and password → Apply
- Hide an active camera on screen — Setting → Camera → Live view → View sub tab → click the cross icon inside the channel → Apply → OK
- Bring a hidden camera back — Setting → Camera → Live view → View → click inside the channel → Apply

### Camera name, OSD and NVR users | class 19 · 13 Nov 2023
